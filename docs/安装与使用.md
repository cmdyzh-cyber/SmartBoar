# 安装与使用

## 安装前

这是 Apple Silicon / macOS 14+ 试用版，只有 HP Laser 108a 开放自动设置。新版安装包未完成真实安装、干净系统和长期打印验证，也未签名公证。需要稳定正式产品时，请等待后续验证版本。

愿意试用时，确认打印机已开机、USB 已接好、有纸张。如果仍重复走纸，先清除旧任务，不要直接发新测试。

## 下载和安装

1. 打开 [v0.2.0 发布页](https://github.com/cmdyzh-cyber/SmartBoar/releases/tag/v0.2.0)。
2. 在 **Assets** 下载 `SmartBoar-0.2.0-arm64-unsigned.pkg`，不是 Source code 压缩包。
3. 双击 PKG，按 macOS 安装提示授权。管理员密码只输入系统授权窗口，不填到网页或 Issue。
4. 从“应用程序”打开“聪明的野猪”。无需终端、Homebrew、Python 或 Xcode。

`SHA256SUMS.txt` 提供发布文件校验值；哈希可用于核对文件一致性，不能代替开发者签名和 Apple 公证。

## macOS 提示无法验证开发者

未签名、公证的下载包可能被拦截。如果你已确认来源是本仓库、核对发布信息并决定试用，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 对这个软件单独授权：尝试打开后，到“系统设置 → 隐私与安全性”找到对应提醒，选择“仍要打开”，再确认“打开”。按钮是否出现受系统版本和管理策略影响。

如果系统提示“将损坏你的电脑”、检测到恶意内容、文件被修改或校验不符，请停止安装并报告提示。单独授权说明不用于绕过这些检测。不需要关闭 SIP、全局关闭 Gatekeeper 或执行解除隔离的终端命令。

## 设置和测试

软件每 10 秒只读检测设备，也可点击“重新检测”。插上打印机不会自动发送打印任务。

| 状态 | 操作 |
|---|---|
| 可自动设置 | 选择设备，点击“自动设置”，按系统提示授权 |
| 已设置 | 放好一张 A4 纸，点击“打印一页测试” |
| 队列已暂停 | 检查旧任务已结束后重新设置 |
| 待适配或需确认信息 | 保存诊断，不手工套用相近型号驱动 |

只有一台已适配设备且没有旧任务时，安装阶段尝试自动设置。未连接、连接多台或有旧任务时，设备设置留到应用中完成；安装成功不等于打印机已经设置成功。

测试每次只提交一份 A4 单面文档。检查真实完整出纸、无重复和条纹。CUPS 显示完成不能证明纸张确实打印出来；失败时不要连续重复发送测试。

## 一直显示任务或重复打印

1. 选中正确设备，点击“清除旧任务”并确认。软件只暂停并清理这一台的电脑端队列。
2. 打印机内部已接收的数据可能还在缓存。用打印机取消键清除；仍走纸时关闭电源，再开机。
3. 确认不再自动走纸后重新设置，最后只测试一页。

## 恢复原设置

选择设备，点击“恢复原设置”，按系统提示授权。还有任务时先清除所选队列的旧任务。

恢复本软件首次设置前的 PPD、USB 地址、启用/暂停状态和设备桥接状态；软件新建的队列会撤销。如果其他软件已改变该队列连接，恢复会停止，避免覆盖另一设备。恢复桥接后可能需重新插拔 USB。

备份在 `/Library/Printers/LegacyPrint/StateV2/<设备哈希>/snapshot.json`，完整备份只允许管理员读取；重复设置不覆盖首次备份。恢复后应用和未使用驱动仍保留，当前没有一键完全卸载。

## 保存诊断和反馈

点击“保存诊断信息”，选择文件位置，不自动上传。文件不含序列号、设备哈希、队列地址、用户名或本地路径。

到 [Issues](https://github.com/cmdyzh-cyber/SmartBoar/issues/new/choose) 选择问题类型。公开反馈前检查附件和截图，不要附密码、序列号、完整 USB 系统转储或私人打印文档。
