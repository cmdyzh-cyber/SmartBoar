# 验证与发布

## 0.2.0 已完成

- Objective-C/AppKit 原生应用、Foundation 管理器和 IOKit USB 工具 ARM64 编译；警告作为错误处理。
- 隔离集成测试：无设备、单/多台设备、重复设备、未知型号、共享 USB ID 名称不匹配、候选机型拒绝安装、规则冲突、缺失/异常序列号。
- 隔离配置测试：旧任务拦截、模块哈希和路径检查、首次备份保留、兼容 PPD 选项保留、只改选中队列、单份测试提交、失败自动恢复、暂停状态恢复、新队列撤销、URI 被外部改动时停止恢复、所选队列取消任务。
- 通过增加一个测试用的第二机型规则，验证管理器可按独立规则运行，不影响其他队列。该测试机型和权限替代不打入生产安装包。
- PKG 生成和展开，驱动模块哈希、版本、root:wheel 权限、可执行文件临时签名、安装脚本范围和 GPL 对应源码检查。
- 本地 A4 文档转换通过，确认仅一页、单份，QPDL 纸张几何为 2480 × 3509；没有发送真实任务。生产管理器在无管理员身份时拒绝配置。
- 应用示例渲染并目视检查。示例中的设备不代表本机检测结果。
- 本机只读预检成功，读取到 macOS 14.6；检测时没有连接的 USB 打印机。

此前 HP 108a 的同一驱动/修复方案已真实打印，包括重新插拔 USB 后测试。该证据支持机型方案，不等同于新版安装包已经完成安装验证。
