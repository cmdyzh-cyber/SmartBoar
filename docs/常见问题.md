# 常见问题

## 哪个文件能安装？

发布页 Assets 中的 `SmartBoar-0.2.0-arm64-unsigned.pkg`。源码 ZIP 和 Source code 不是安装包。

## 所有老打印机都能用吗？

不能保证。当前只有 HP Laser 108a 开放自动设置，另 10 个候选机型只识别、不安装。其他设备有可读取信息时显示状态，但厂商自定义 USB 接口可能还无法识别。

## 108a 方案实测过，为什么新版安装包还未实测？

同一驱动和 USB 修复曾在 M3 / macOS 14.6 实际出纸，并验证 USB 重连。后来写成的新版安装器只完成编译、隔离配置/回滚和包检查，还没有实际安装和出纸验证。这两项证据分别记录。

## HP 107a、1008a、MFP 13x 也能安装吗？

当前不开放。参考项目的其他型号验证不能作为本项目证据。共享 USB 标识还需要核对完整产品名，不能混用。

## 会影响其他打印机或关闭 SIP 吗？

不需要关闭 SIP，不全局关闭 USB/IPP，不改变默认打印机。仅设置所选设备精确对应的 USB 队列。

## 需要输入几次密码？

安装需要系统管理员授权。如果当时无法设置设备，后来在应用中设置、恢复或清理队列，系统可能再次请求授权。只读检测和测试打印通常无需管理员权限。密码只输入系统窗口。

## 识别不了、没有序列号或有多个队列？

当前拒绝不可靠或重复身份，多个对应队列也会停止设置。先确认接线、电源和目标队列，再保存诊断，不盲目删除其他设备的队列。

## 显示完成却没出纸，或者不停打印？

电脑端任务状态不等于实际出纸。停止重复提交，按[使用说明](安装与使用.md)清除所选队列旧任务和机内缓存，最后只测试一页。

## 会下载驱动或上传数据吗？

0.2.0 没有在线驱动库。适配库随版本更新，诊断只保存本地，不自动上传。你手工附到 GitHub Issue 的内容会公开。

## 其他系统、网络打印、扫描和传真？

当前不支持 Windows、Intel Mac、无线打印、扫描和传真。本版面向 Apple Silicon / macOS 14+ / USB 打印。

## 名字和卸载？

新队列显示“聪明的野猪 · 实际机型”，旧队列名称保留。可在系统设置改显示名。

先恢复原设置，确保队列不再引用本软件驱动；再退出应用并将其移到废纸篓。驱动和备份文件仍留存，当前不提供一键完整卸载，恢复按钮不是卸载。
